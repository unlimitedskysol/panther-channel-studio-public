Panther Channel Studio V8.4.0
Windows 10/11 x64

Official website:
https://studio.panthergame.app/

V8.4 changes:
- Native Panther host window with Panther taskbar identity.
- No separate visible Edge application window or random session title.
- Rebuilt Arabic layout without reversing the whole application canvas.
- Responsive toolbars, tabs, metrics and Diagnostics at high zoom.
- Technical values remain left-to-right in Arabic mode.
- Zoom range remains 75% to 150%.
- V8.3 fatal-only export validation is retained.

Important:
The interface still uses the installed Microsoft Edge rendering engine internally,
but Edge is attached inside the Panther native host window and should not appear
as a separate application or taskbar item.
